\section{Data Availability}
All data used in this manuscript are publicly available; no new
mass spectrometry data were generated. The Leduc \cite{leduc} and Petrosius
\cite{petro} datasets were downloaded using the \texttt{scpdata} \cite{scp_paper, scp_replication} package from Bioconductor.
The \texttt{scpdata} package redistributes publicly available SCP data using
R/Bioconductor data containers. The Leduc and Petrosius data were downloaded from
the Slavov laboratory website (\url{https://scp.slavovlab.net/Leduc_et_al_2022})
and Zenodo (\url{https://zenodo.org/records/8146605}), respectively. The raw data
and quantification data can also be found in the MassIVE repositories
MSV000089159 (\url{https://doi.org/10.25345/C5W950S0W}) and
MSV000092429 (\url{https://doi.org/10.25345/C5DB7W12H}), respectively.

\section{Code Availability}
All code used to prepare and analyze the datasets and produce the figures of this manuscript is available through GitHub (\url{github.com/statOmics/gamdid_paper}).
The results in this manuscript were obtained with \texttt{gamdid} version 0.99.0, archived as a GitHub release (\url{https://github.com/statOmics/gamdid/releases/tag/v0.99.0}).
